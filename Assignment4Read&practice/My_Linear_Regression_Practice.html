1 About this practice

I am using this file to practise linear regression in R. I used a small sample dataset to understand simple regression, multiple regression, prediction and diagnostic plots.

The data in this exercise is created for practice. It is not real student data.

5 4. Correlation

Correlation measures the direction and strength of a linear relationship between two numeric variables. It ranges from -1 to +1.

  • Positive correlation: the variables tend to increase together.
  • Negative correlation: one tends to decrease as the other increases.
  • Correlation near zero: little linear association.

Correlation does not prove that one variable causes another.

cor(
  regression_data$Study_Hours,
  regression_data$Marks,
  method = "pearson"
)
#> [1] 0.9988195
# Correlations among all numeric variables.

6 5. Simple linear regression

Simple linear regression uses one predictor. Here I predict Marks using Study_Hours.

The formula Marks ~ Study_Hours means:

  • Marks is the response variable (Y).
  • Study_Hours is the predictor variable (X).
simple_model <- lm(
  Marks ~ Study_Hours,
  data = regression_data
)

The intercept is the estimated mark when study hours are zero. The slope estimates the change in marks for one additional study hour, according to this model.

I also check the fitted values and residuals. A residual is the observed value minus the fitted value.

regression_data$Fitted_Marks <- fitted(simple_model)
regression_data$Residuals <- residuals(simple_model)

7 6. Making predictions

I use predict() to estimate marks for new study-hour values. The new data must use the same predictor name as the model.

new_students <- data.frame(
  Study_Hours = c(3, 5, 7, 8)
)

predicted_marks <- predict(
  simple_model,
  newdata = new_students
)

data.frame(
  Study_Hours = new_students$Study_Hours,
  Predicted_Marks = as.numeric(predicted_marks)
)

I can request a confidence interval for the estimated mean response.

predict(
  simple_model,
  newdata = new_students,
  interval = "confidence"
)

I compare the R-squared values, but I do not choose a model using R-squared alone. I also need to consider assumptions, data quality, adjusted R-squared and the purpose of the analysis.

simple_summary <- summary(simple_model)
multiple_summary <- summary(multiple_model)

data.frame(
  Model = c("Simple regression", "Multiple regression"),
  R_Squared = c(
    simple_summary$r.squared,
    multiple_summary$r.squared
  ),
  Adjusted_R_Squared = c(
    simple_summary$adj.r.squared,
    multiple_summary$adj.r.squared
  ),
  Residual_Standard_Error = c(
    simple_summary$sigma,
    multiple_summary$sigma
  )
)

10 9. Main linear regression assumptions

These are the four main assumptions I am reviewing.

  1. Linearity: the relationship between predictors and response should be reasonably linear.
  2. Independence: observations/errors should be independent. This depends on how the data was collected and ordered.
  3. Homoscedasticity: residuals should have roughly constant variance across fitted values.
  4. Normality of residuals: residuals should be approximately normally distributed for standard small-sample inference.

Diagnostic plots help me look for warning signs. They do not prove that an assumption is satisfied.

11 10. Diagnostic plots

The four standard diagnostic plots from plot(lm_model) are:

  1. Residuals vs Fitted: checks linearity and whether residual spread is roughly constant.
  2. Normal Q-Q: checks whether residuals are approximately normal.
  3. Scale-Location: another check of constant residual spread.
  4. Residuals vs Leverage: helps identify observations that may have strong influence.
par(mfrow = c(2, 2))
plot(simple_model)

par(mfrow = c(1, 1))

These plots do not prove independence. I also need to consider how the observations were collected.

12 11. Checking residual normality

I use a histogram and Q-Q plot to inspect the residual distribution.

model_residuals <- residuals(simple_model)

hist(
  model_residuals,
  main = "Histogram of Regression Residuals",
  xlab = "Residuals",
  col = "lightblue",
  border = "white"
)

qqnorm(model_residuals)
qqline(model_residuals, col = "red")

I can also run the Shapiro-Wilk test. Its null hypothesis is that the data are consistent with a normal distribution. I interpret the p-value together with the Q-Q plot, not by itself.

shapiro.test(model_residuals)
#> 
#>  Shapiro-Wilk normality test
#> 
#> data:  model_residuals
#> W = 0.90306, p-value = 0.1737

16 My short summary

  • Simple linear regression uses one predictor.
  • Multiple linear regression uses two or more predictors.
  • lm() fits a linear regression model.
  • summary() displays the model results.
  • coef() extracts the estimated coefficients.
  • predict() makes predictions for new data.
  • Residuals are observed values minus fitted values.
  • Diagnostic plots help me check regression assumptions.
